# 对抗测试适用范围

范围为 `lot_operation_inventory`。下表对应 `tests/test_adversarial_matrix.py` 的确定性测试断言，不表示 26 类目标全部完成。模型草稿的语法、结构化协议及受控传输测试另见 `tests/test_model_planner.py`；这些不等同于真实供应商红队评测。

```shell
python -m unittest discover -s tests -p test_adversarial_matrix.py -v
```

测试在临时目录生成较大合成夹具并重算 manifest/覆盖声明；不修改随包数据，不读取外部标准答案代替业务计算。`MDLAB_ACCEPTANCE_DIR` 只在测试中导出本地响应，不是产品 HTTP 故障开关。

## 阅读边界

表内“当前切片”指当前 LOT 清单范围，“部分”指该类还包含尚不支持的业务语义。测试数量、表格行数和已通过的类别数不是同一指标。浏览器布局、真实上游故障、生产压力及跨平台不能由后端函数测试推定通过；当前回归环境与限制见 [测试说明](testing.md)。
