# 合成数据说明

随项目提供的 `data/batches/demo-v1` 是专为本演示构造的确定性合成场景，不是生产系统的数据导出。产品、设备、载具、批次、单件编号、时间、报警、测试结果和业务规则均为虚构。TEST_A / TEST_B / TEST_C 只表示三个抽象测试关卡，不对应具体工艺或检测标准。

场景包含 4 个 LOT、40 个单件、14 次作业、106 次测试尝试的 107 个记录版本，以及 113 次投递（其中 6 次为重复投递）。十二张 CSV 与一份原始投递流的摘要和计数保存在 manifest 中，应用导入前核对文件完整性。

数据用于演示通用软件问题：主外键关系、结果更正、迟到记录、复测、历史身份绑定、时间可见性、重复投递、缺失证据和规则冲突。它不代表任何组织的数据库结构、真实异常分布、设备能力或质量标准。

`recorded_at` 控制记录在历史查询中何时可见；`as_of` 是用户明确选择的业务历史截止时刻。随包覆盖声明只适用于这一封闭合成场景，不能证明现实数据采集完整。

源文件的 schema 元数据保留其冻结时的契约版本和状态；这些字段不是当前阶段的验收结论。当前能力、验证结果和未支持范围以 SPEC 及验收文档为准。

项目实现、文档、合成数据与评测问题按根目录 MIT 许可证提供。第三方软件保留各自许可证；运行时生成的本地数据库、会话、请求原话、密钥和日志不属于公开样本，不能加入版本控制。
